# Project Statement

## Problem Statement

Students often spend small amounts on food, travel, books, shopping and other daily needs. When these expenses are not written down, it becomes difficult to know where the money is going.

The Expense Tracker is a simple Python program that helps a student record expenses and check the total amount spent.

## Scope

The project covers:
- Adding expenses
- Viewing saved expenses
- Deleting an expense
- Monthly reporting
- Category-wise reporting
- Setting a monthly budget
- Checking remaining budget
- Saving data in a JSON file

The project is designed for a single user and runs locally on a computer.

## Target Users

The main target users are college students who want a simple way to keep track of daily spending.

## High-Level Features

1. Add expense
2. View expenses
3. Monthly report
4. Category report
5. Delete expense
6. Set monthly budget
7. View budget status
8. Local JSON storage
